MEANDER Μ38 — ΔΙΑΔΟΧΙΚΕΣ ΟΙΚΟΓΕΝΕΙΕΣ, RANK64 — 05/11/2026

Αποσυμπίεσε σε ΝΕΟ φάκελο. Το παλιό καλύτερο πακέτο δεν αντικαθίσταται.
Προτεινόμενη εκκίνηση σε Linux server με την πραγματική κατανομή RAM/CPU:

  bash START_M38.sh

Προεπιλογή: 4 ομάδες, έως 16 επιτρεπόμενα νήματα, 16 GiB περιθώριο.
Το πρώτο βήμα εγκαθιστά ιδιωτικό .venv αν λείπει, έπειτα εκτελεί τους
πραγματικούς ελέγχους Linux και μόνο μετά ξεκινά η αριθμητική σειρά Μ38.
Χρειάζονται Python 3.11–3.14 64-bit και venv. Προτείνεται η ίδια Python
του επιτυχημένου Μ37. Δεν χρειάζονται GPU, compiler C++ ή sudo.

Αν υπάρχει έτοιμη Python με numpy2.3.5 / numba0.68.0 / psutil7.2.2:

  MEANDER_PYTHON=/absolute/path/to/.venv/bin/python bash START_M38.sh

Για ρητά 16 νήματα ή 3 ομάδες:
  MEANDER_THREADS=16 bash START_M38.sh
  MEANDER_GROUPS=3 bash START_M38.sh --output runs/M38_G3

Οι 4 ομάδες είναι η αρχική επιλογή μικρότερης RAM. Η κορυφή ολόκληρου Μ38
δεν έχει ακόμη μετρηθεί. Η επιτυχία μικρότερων τάξεων και ο αρχικός έλεγχος
σταθερών πινάκων ΔΕΝ αποτελούν εγγύηση ολοκλήρωσης σε 2 TB.
Το πρόγραμμα χρησιμοποιεί τα πραγματικά διαθέσιμα bytes και το όριο cgroup,
όχι την ονομαστική μνήμη του host. Δεν αυξάνει/μεταβάλλει όρια συστήματος.

Έλεγχος μόνο πόρων/διαστάσεων, χωρίς μεγάλο υπολογισμό:
  .venv/bin/python server_meander.py 38 --groups 4 --inspect

Πρώτα πρέπει να έχει τελειώσει οποιαδήποτε άλλη μεγάλη αριθμητική εργασία.
Δεν εκκινούνται ταυτόχρονα ομάδες: κάθε ομάδα χρησιμοποιεί τα επιλεγμένα
νήματα παράλληλα εσωτερικά, ολοκληρώνεται και η διεργασία της κλείνει.
Η επόμενη ξεκινά σε καθαρή διεργασία. Τα επιτρεπόμενα μεγέθη πρώτου κλάδου
t=1..19 μοιράζονται ανά υπόλοιπο διαίρεσης με το πλήθος ομάδων.
Όλες οι ομάδες συμπεριλαμβάνονται, χωρίς διπλομέτρηση ή φίλτρο απόρριψης.
Η ακριβής σταθμισμένη κάλυψη ελέγχεται έναντι Catalan(38).

Η έκδοση engine64 χρησιμοποιεί int64 για ranks, maps και μεταφρασμένους
δείκτες, ώστε να καλύπτει τα 6.768.687.870 ranks του Μ38. Οι αριθμητικοί
πυρήνες συντελεστών παραμένουν οι καθιερωμένοι μεταβλητού πλάτους.
Κάθε μπλοκ πιστοποιείται με ελεγμένη ακριβή αριθμητική έως 128 bits πριν
από εγγραφές. Αν το cap δεν χωρά, η ομάδα σταματά με σφάλμα· δεν τυλίγει
και δεν αποδέχεται πλασματική επιτυχία. Το άνω όριο C38² είναι 135-bit,
ενώ η τελική άθροιση/κάλυψη γίνονται με αυθαίρετης ακρίβειας Python integers.

ΑΠΑΓΟΡΕΥΕΤΑΙ MATRIX SPILL: δεν δημιουργούνται αρχεία πινάκων, memmap ή
αρχεία συντελεστών. Οι πίνακες παραμένουν σε ανώνυμη RAM. Τα JSON/logs,
η JIT cache και το .venv χρησιμοποιούν κανονικά δίσκο και καταγράφονται
χωριστά από matrix I/O. Οι φρέσκοι έλεγχοι πόρων δεν απενεργοποιούνται.
Το λειτουργικό σύστημα διαχειρίζεται μόνο του την εικονική μνήμη.

Αποτελέσματα: runs/M38_G4/RESULT.json και Mn.txt. Κάθε group_XX έχει
RESULT.json, STAGES.jsonl, stdout.log, PREFLIGHT.json και STATE.json.
Οι χρόνοι και RSS όλων των ομάδων καταγράφονται χωριστά. Η RSS δεν
ταυτίζεται με τα bytes συντελεστών. Η πρώτη JIT δεν αφαιρείται αυθαίρετα.

Η επανεκτέλεση START_M38.sh κρατά τις επαληθευμένες ολοκληρωμένες ομάδες
του ίδιου κώδικα/πλάνου και συνεχίζει τις υπόλοιπες. Οι συντελεστές μιας
ημιτελούς ομάδας δεν αποθηκεύονται· αυτή ξαναρχίζει από την αρχή.
Για αλλαγή πηγών, ομάδων ή νημάτων χρησιμοποίησε διαφορετικό --output.
Σε πίεση μνήμης σταματά η δική μας εργασία, χωρίς υποχώρηση σε δίσκο.
Ctrl+C σταματά τον controller και τον δικό του worker, όχι τον server.

Η engine32 περιλαμβάνεται ανέπαφη μόνο ως αναφορά μικρότερων συγκρίσεων.
Τα τοπικά tests και μετρήσεις βρίσκονται στα LOCAL_VALIDATION.json και
LOCAL_COMPARISON.json. Δεν ισχυριζόμαστε ήδη ολοκληρωμένο Μ38 ή ανεξάρτητη
CRT. Το ολοκληρωμένο Μ37/οποιαδήποτε προηγούμενη παράδοση μένει ανέπαφο.
